## Why NX

<CardGrid>
  <Card title="Markup and logic together" icon="puzzle">
    Elements, functions, `if` and `for` are all expressions of one language. There is no separate
    template syntax, and no code-behind file.
  </Card>
  <Card title="Typed all the way through" icon="approve-check">
    Records, unions and components are checked before anything runs. A missing property or a
    misspelled case is a compile error with a precise location.
  </Card>
  <Card title="Runs where your app runs" icon="rocket">
    Evaluate NX from .NET with `NxLang.Sdk`, or compile it to NX IR in the browser or Node with
    `@nx-lang/sdk-wasm` and run it with `@nx-lang/ir-runtime`.
  </Card>
  <Card title="Good tooling from day one" icon="pencil">
    One compiler powers the language service behind hover, completion and diagnostics, in the
    editor and in the playground.
  </Card>
</CardGrid>
